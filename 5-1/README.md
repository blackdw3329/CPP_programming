# 실습과제1

## 1. 인자와 매개변수를 구분하여 설명하시오.
> 인자는 함수를 호출할 때 전달하는 값이고, 매개변수는 전달받은 값을 저장하는 변수입니다.

---

## 2. 함수 호출시 자동으로 처리되는 2가지는 무엇인가?
> 매개변수 메모리가 할당되고, 전달된 인자값으로 매개변수가 초기화됩니다.

---

## 3. 값에 의한 호출로 다른 함수에서 선언된 변수의 값을 변경할 수 없다. 이유를 설명하라.
> 값에 의한 호출은 변수의 복사본이 전달되므로 원본 변수의 값이 변경되지 않습니다.

---

## 4. 주소에 의한 호출을 사용해야하는 경우를 2가지 이상 설명하라.
> 함수에서 원본 변수 값을 변경해야 할 때 사용합니다.  
> 배열이나 객체처럼 큰 데이터를 효율적으로 전달할 때 사용합니다.

---

## 5. 인자가 객체인 경우는 어떤 호출방식이 좋은가? 이유도 설명하라.
> 주소에 의한 호출이 좋습니다. 객체 복사를 줄여 메모리 사용과 실행 속도를 효율적으로 관리할 수 있기 때문입니다.

---

## 6. 함수 반환과정에서 자동으로 처리되는 2가지는 무엇인가?
> 임시변수 메모리가 할당되고, 반환값으로 초기화됩니다.

---

## 7. 함수 반환과정에서 임시변수가 필요한 이유를 설명하라.
> 함수 종료 후에도 반환값을 유지하여 호출한 곳에서 사용할 수 있도록 하기 위해 필요합니다.

---
